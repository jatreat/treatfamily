# treatfamily.org

The Treat family's page: the games, the notable Treats, the line from Pitminster, and a link to Friends of Pitminster.

Edit `build.py` (the people, the line, the text) and run `python3 build.py` to regenerate `index.html`, or edit `index.html` directly. The games live in `games/`; replace a file there to update a game.

Hosting: Cloudflare Pages, no build command, output directory `/`. Domain: treatfamily.org (nameservers at Cloudflare; the iCloud mail records are in the Cloudflare DNS zone).
